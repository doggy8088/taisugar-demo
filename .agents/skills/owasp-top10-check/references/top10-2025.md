# OWASP Top 10:2025 檢核參考

分類來源：[OWASP Top 10:2025](https://top10.owasp.org/2025/)，查核日期：2026-10-14。以下提示為本技能整理，不是 OWASP 官方逐條驗收標準。依實際功能追蹤證據，不能僅憑設定或 API 名稱判定漏洞。

| 分類 | 檢查提示 | 證據與常見誤判 |
| --- | --- | --- |
| A01:2025 存取控制失效（Broken Access Control） | 匿名、一般使用者、管理者的功能與物件權限；跨使用者／跨租戶存取、直接物件參照、路徑穿越、靜態敏感檔、CSRF、SSRF 目的地限制。 | 追蹤敏感讀寫入口的授權及資料範圍。隱藏按鈕不構成授權；控制器可能已有全域政策。依瀏覽器自動附帶憑證判定 CSRF；CORS 不等於伺服器授權。 |
| A02:2025 安全設定錯誤（Security Misconfiguration） | 正式環境除錯頁、預設帳號、不必要端點、CORS、Cookie、HTTPS／HSTS、代理信任、檔案權限與安全標頭。 | 分辨開發設定、正式設定及部署覆寫。缺少標頭不自動構成高風險；確認內容與可利用方式。 |
| A03:2025 軟體供應鏈失效（Software Supply Chain Failures） | 直接與間接依賴、套件來源與版本鎖定、弱點公告、CI 權限、建置工具及產物發布鏈。 | 記錄解析版本與公告範圍，分辨建置期及執行期暴露。套件掃描無告警不能證明整個供應鏈安全。 |
| A04:2025 密碼學失效（Cryptographic Failures） | 敏感資料傳輸／儲存、密碼雜湊、金鑰管理、亂數、加密模式及權杖簽章。 | 追蹤資料及密鑰生命週期。編碼或一般雜湊不等於加密；密碼儲存應檢查專用密碼雜湊。證據僅保留遮罩值。 |
| A05:2025 注入（Injection） | SQL、命令、模板等直譯器入口；儲存型、反射型及 DOM XSS；資料跨越語法邊界的位置。 | ORM 仍須檢查原始查詢及動態排序；Razor 編碼須追到 Raw、JavaScript、URL 等輸出情境。確認輸入可達危險用法且缺乏有效防護。 |
| A06:2025 不安全設計（Insecure Design） | 業務流程濫用、權限與信任邊界、資源配額、重複提交、競爭條件、財務狀態轉換。 | 用業務不變條件與濫用案例驗證。缺少威脅模型文件不是漏洞本身；交易、唯一限制及伺服器驗證可能已維護規則。 |
| A07:2025 身分驗證失效（Authentication Failures） | 登入暴力嘗試、預設憑證、帳號復原、MFA、工作階段固定、過期與登出撤銷、權杖驗證。 | 先確認本機、閘道及身分提供者的責任，核對簽發者、受眾、效期與實際設定。登入成功不代表通過物件授權。 |
| A08:2025 軟體或資料完整性失效（Software or Data Integrity Failures） | 不受信任更新／匯入、反序列化、簽章與完整性驗證、客戶端可改寫的權限或帳務資料。 | 追蹤來源及驗證，確認輸入是否被當成可信物件或程式執行。與 A03 重疊時按根因選主分類，避免重複計數。 |
| A09:2025 安全日誌與警示失效（Security Logging and Alerting Failures） | 登入失敗、權限拒絕、管理操作、帳務異動的記錄、完整性、保留、敏感資料遮罩及警示。 | 追蹤事件能否進入可處理的監控流程。原始碼通常無法證明正式警示配置，應列待驗證；有日誌不代表有告警及處理機制。 |
| A10:2025 例外狀況處理不當（Mishandling of Exceptional Conditions） | 驗證失敗時預設放行、未捕捉例外、逾時、部分寫入、交易回復、資源清理、重試與重複處理。 | 追蹤失敗路徑、最終資料狀態及回應，使用隔離故障測試。不能只因有 catch 就判定安全，也不能以正式系統故障注入補證據。 |

版本注意：SSRF 在 2025 併入 A01；A03 涵蓋供應鏈；A10 改為例外狀況處理。指定 2021 等舊版時，從該版官方文件重新取得分類，不能只替換年份。
