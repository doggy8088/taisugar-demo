# 操作與備份

**初次使用**

1. 建立資產，例如一棟商辦。
2. 為資產建立出租單位，例如 3 樓 A 室。整棟出租則建立「整棟」單位。
3. 建立承租戶，填寫主要聯絡人與電話。
4. 建立租約，選取單位與承租戶，輸入租期、月租、押金及繳款日，狀態改為有效。
5. 在應收帳款頁選取月份，按「產生租金應收」。
6. 實際收款後，在收款紀錄頁選取應收帳款及金額。
7. 回到營運總覽查看出租情形、實收及待追蹤帳款。

**水電操作**

先建立水電表，再在抄表紀錄輸入日期、前次與本次讀數及本期單價。畫面列表會顯示計算金額。確認費用後，到應收帳款建立對應租約的水費或電費帳款；目前不自動轉單。

**更正與刪除**

- 未被其他資料使用的資產等主檔，可以在刪除確認頁刪除。
- 已有租約或其他關聯的資料，改用停用或終止。仍有有效租約的資產／單位，必須先處理租約。
- 收款金額登錯：先將原收款改為作廢，再新增正確收款。
- 已有收款的應收，不可直接變更金額或歸屬。
- 有帳務的租約不可直接更換承租戶、出租單位或租金。續約應建立新租約。

**備份與還原**

目前沒有自動備份排程。正式排程前，可以採取以下離線備份方式：

1. 停止網站，確認沒有其他程序正在使用資料庫。
2. 完整複製 `App_Data` 目錄到帶日期的備份目錄。若使用自訂連線字串，備份該路徑的資料庫及同名 `-wal`、`-shm` 檔案。
3. 將備份保存於不同磁碟或受控儲存空間。
4. 還原時先停站，保留目前資料副本，再以備份替換完整資料檔案。
5. 重新啟動網站，抽查資產、租約、應收及收款筆數。

網站運作中不可只複製 `.db` 而忽略 WAL 狀態。需要不中斷備份時，應使用 SQLite Backup API 或具一致性保證的備份工具。
