# 操作與備份

**初次使用**

1. 建立資產，例如一棟商辦。
2. 為資產建立出租單位，例如 3 樓 A 室。整棟出租則建立「整棟」單位。
3. 建立承租戶，填寫主要聯絡人與電話。
4. 建立租約，選取單位與承租戶，輸入租期、月租、押金及繳款日，狀態改為有效。
5. 在應收帳款頁選取月份，按「產生租金應收」。
6. 實際收款後，在收款紀錄頁選取應收帳款及金額。
7. 回到營運總覽查看出租情形、實收及待追蹤帳款。

**水電操作**

先建立水電表，再在抄表紀錄輸入日期、前次與本次讀數及本期單價。畫面列表會顯示計算金額。確認費用後，到應收帳款建立對應租約的水費或電費帳款；目前不自動轉單。

**3D 物業全景**

- 在營運總覽點選建物或物業清單，展開該物業的樓層；選擇樓層可單獨查看其中的單位。
- 點選單位可查看承租戶、租約期間、月租與目前逾期未收金額，並前往原有單位或租約編輯頁。
- 單位顏色表示出租中、空置中、維修中、自用或停用；「欠款」與「到期」另外標示，到期指有效租約將於未來 90 天內到期。
- 拖曳場景可旋轉，滾輪或放大／縮小按鈕可調整視野。「重設視角」恢復目前視圖，「全部物業」返回總覽。
- 搜尋支援物業名稱、地址、單位名稱、編號、樓層及承租戶。鍵盤可操作清單、樓層選單與單位展開項目。
- 手機使用場景下方的物業與單位面板。不支援 3D 時會保留清單操作；關閉 JavaScript 時仍可展開原生資料清單與使用編輯連結。
- 場景按既有樓層文字產生示意排列，不代表真實建物格局、地理位置或尺寸。空間使用狀態依所選月份的快照日期顯示，逾期帳款則一律截至今日。
- 系統啟用「減少動態效果」時，鏡頭立即切換視圖，不播放過場。場景閒置時不持續繪圖，也不自動旋轉。

**工傷管理與人體部位標記**

從左側「安全與健康 → 工傷管理」或 `/injuries` 開啟。可直接點選 3D 人體或其部位標籤，也可用右側核取方塊選取；再次點選會取消，支援同時標記多個位置。

- 「正面／背面／左側／右側」切換觀察方向；左右一律以當事人自身為準。「骨架參考」顯示簡化骨架，協助辨識位置。
- 用「聚焦部位」查看頭頸、軀幹或單側肢體，並用搜尋尋找手指、腳趾等細部位置。內部、全身性及其他未明部位可從清單選取。
- 下方顯示已選部位，可逐項移除或清除全部。「確認選取」整理本次摘要；此頁不會建立個案、不會將選取結果寫入資料庫，重新整理後需重新標記。
- 無法顯示 3D 時，仍可使用部位清單。圖形為標記位置的示意，不表示診斷結果或完整醫學解剖構造。

**更正與刪除**

- 未被其他資料使用的資產等主檔，可以在刪除確認頁刪除。
- 已有租約或其他關聯的資料，改用停用或終止。仍有有效租約的資產／單位，必須先處理租約。
- 收款金額登錯：先將原收款改為作廢，再新增正確收款。
- 已有收款的應收，不可直接變更金額或歸屬。
- 有帳務的租約不可直接更換承租戶、出租單位或租金。續約應建立新租約。

**備份與還原**

目前沒有自動備份排程。正式排程前，可以採取以下離線備份方式：

1. 停止網站，確認沒有其他程序正在使用資料庫。
2. 完整複製 `App_Data` 目錄到帶日期的備份目錄。若使用自訂連線字串，備份該路徑的資料庫及同名 `-wal`、`-shm` 檔案。
3. 將備份保存於不同磁碟或受控儲存空間。
4. 還原時先停站，保留目前資料副本，再以備份替換完整資料檔案。
5. 重新啟動網站，抽查資產、租約、應收及收款筆數。

網站運作中不可只複製 `.db` 而忽略 WAL 狀態。需要不中斷備份時，應使用 SQLite Backup API 或具一致性保證的備份工具。


**營運總覽動畫與圖表操作**

開啟營運總覽時，指標數字會逐步累加，租金長條按月份依序展開，出租率圓環在進入畫面時填入。右上角「重播動態」可再次播放。動畫只改變呈現方式，帳款計算與最終數值不變。

- 將滑鼠移到月份長條上，或在手機輕點月份，可查看該月應收與實收金額。
- 鍵盤 Tab 可聚焦月份，左右方向鍵切換月份，Home／End 跳到第一／最後一個月份。
- 「查看圖表數據」保留可讀的完整數據表。
- 系統啟用「減少動態效果」時，網站直接顯示最終數字與圖形，隱藏重播按鈕；動畫播放中切換設定也會立即停止。
- 動畫使用瀏覽器原生 API，沒有新增前端套件或外部網路依賴。
